### ◆ SnapCode — AI 해커톤 심사 플랫폼 `2025`

> *“참가자들은 과연 공정하게 평가받고 있을까?”*

해커톤 참가자로서 품었던 질문에서 시작해, 친구 2명과 사이드 프로젝트로 AI 심사 플랫폼을 만들었습니다.<br/>
**멋쟁이사자처럼에 직접 제안해 공식 심사 툴로 채택됐고**, 대학생 **1,500명**이 참가한 13기 중앙 해커톤과 창업 트랙(루트임팩트)의 1차 심사를 맡았습니다.

- ⚡ 전체 제출물 AI 1차 평가 **30분** 만에 완료
- 📊 루브릭 기반 채점 + **백분위 리포트**로 팀별 위치 제공
